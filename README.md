# Turkey Navigation
Turkey Navigation is a Java-based application that calculates the shortest paths between cities on a given map using Dijkstra’s algorithm, and displaying this path to the user using StdDraw library. This project was developed as part of the coursework for CMPE160: Object Oriented Programming at Bogazici University during the Spring 2024 semester.

The program takes a list of cities with their coordinates and allows the user to find the shortest route and distance between any two cities using the given map data.

# Instructions
When prompted, enter the name of the departure city.

Then, enter the name of the destination city.

The program calculates and displays the shortest distance between the two cities and the optimal route for that travel.
